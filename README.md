# 🛍️ Piran Shop (পিরান শপ) - আধুনিক অনলাইন মেগা মার্কেটপ্লেস

বিশ্বমানের ডিজাইন এবং প্রযুক্তিতে তৈরি **ওয়েব ও মোবাইল অ্যাপ (Web + Android/iOS)** প্ল্যাটফর্ম।

---

## 🏗️ আর্কিটেকচার স্ট্রাকচার (Monorepo)

```
piran-shop/
├── backend/            # সেন্ট্রালাইজড REST API সার্ভার (Express + Node.js)
│   ├── data/           # প্রোডাক্ট, ক্যাটাগরি ও অর্ডারের ডেটাবেজ (JSON Store)
│   ├── server.js       # লাইভ API ইঞ্জিন (Port: 5000)
│   └── package.json
│
├── web/                # প্রিমিয়াম রেসপন্সিভ ওয়েবসাইট (Vite + React + Tailwind CSS v4)
│   ├── src/
│   │   ├── components/ # হেডার, ব্যানার, স্লাইড কার্ট, ফ্ল্যাশ সেল, চেকআউট, ট্র্যাকিং
│   │   ├── App.jsx     # মূল অ্যাপ ও লাইভ স্টেট
│   │   └── index.css   # আধুনিক স্টাইলিং ও টাইপোগ্রাফি
│   ├── vite.config.js  # Port: 3000
│   └── package.json
│
└── mobile/             # ক্রস-প্ল্যাটফর্ম মোবাইল অ্যাপ (React Native / Expo)
    ├── src/
    │   └── services/   # ব্যাকএন্ড API ক্লায়েন্ট
    ├── App.js          # অ্যান্ড্রয়েড ও আইওএস UI ও কার্ট ইঞ্জিন
    └── package.json
```

## ⚡ লাইভ রান করার নির্দেশিকা

### ১. ব্যাকএন্ড সার্ভার (Backend Server)
```bash
cd backend
npm run dev
# রানিং পোর্ট: http://localhost:5000
```
* **API Endpoints:**
  * `GET /api/products` - সব পণ্য ও ফিল্টারিং
  * `GET /api/deals` - ফ্ল্যাশ সেল
  * `POST /api/orders` - নতুন অর্ডার গ্রহণ
  * `GET /api/orders/:id` - লাইভ অর্ডার ট্র্যাকিং

### ২. ওয়েবসাইট (Web Application)
```bash
cd web
npm run dev
# ব্রাউজারে ওপেন করুন: http://localhost:3000
```

### ৩. মোবাইল অ্যাপ (Android & iOS via Expo)
```bash
cd mobile
npm install
npx expo start
# মোবাইলে Expo Go অ্যাপ দিয়ে QR কোড স্ক্যান করলেই লাইভ অ্যাপ চলবে!
```
